# mnirs: Muscle Near-Infrared Spectroscopy Processing and Analysis

Read, process, and analyse data from muscle near-infrared spectroscopy
(mNIRS) devices. Import raw data from file and return time-series data
and metadata. Standardised methods for cleaning, filtering,
transforming, and analysing mNIRS data. Custom plot theme and colour
palette. Intended for mNIRS researchers and practitioners in exercise
physiology, sports science, and clinical practice.
